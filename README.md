# ☕ Estudos de Java - Orientação a Objetos

Repositório destinado ao estudo e prática de Programação Orientada a Objetos (POO) com Java.
Aqui estão os exercícios práticos focados em Classes, Atributos, Métodos e Encapsulamento.

## 🚀 Tecnologias Utilizadas
* **Java** (JDK)
* **Eclipse IDE**
* **Git & GitHub**

## 📂 Lista de Exercícios

### 1. Rectangle (Geometria)
Programa para calcular as medidas de um retângulo com base na largura e altura fornecidas pelo usuário.
* **Conceitos:** Criação de classes, métodos com retorno (`double`), uso da classe `Math`.
* **Funcionalidades:** Cálculo de Área, Perímetro e Diagonal.

### 2. Employee (Gestão de Salário)
Sistema simples para gestão de funcionários.
* **Conceitos:** Métodos `void` vs com retorno, encapsulamento básico, formatação de Strings.
* **Funcionalidades:** Cálculo de Salário Líquido (descontando imposto) e método para aumentar o salário baseado em porcentagem.

### 3. Student (Sistema de Notas)
Sistema de avaliação de alunos baseado em três notas trimestrais.
* **Conceitos:** Lógica de aprovação/reprovação dentro da classe, delegação de responsabilidade.
* **Funcionalidades:** Verifica se o aluno passou (Média >= 60.0) ou se reprovou, informando quantos pontos faltaram.

## 📦 Como executar
1. Clone o repositório.
2. Importe o projeto no **Eclipse IDE**.
3. Execute o arquivo `Program.java` (ou `Programa2.java`) dentro do pacote `application`.
